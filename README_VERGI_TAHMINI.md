# Paket 9 - Vergi Tahmini

Bu pakette şahıs şirketi kullanımı için tahmini vergi ekranı eklendi.

## Eklenenler

- Diğer menüsüne **Vergi Tahmini** ekranı
- Aylık KDV özeti
- Ödenecek / devreden KDV hesabı
- Geçici vergi dönemleri
- Yıllık tahmini gelir vergisi
- 2026 ücret dışı gelir vergisi tarifesine göre tahmini şahıs şirketi hesabı

## Dikkat

Bu ekran resmi beyan yerine geçmez. Bağ-Kur, geçmiş yıl zararları, istisnalar, indirilecek giderler, tevkifatlar ve mali müşavir düzeltmeleri dahil değildir.
